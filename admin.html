GitHub 設定
設定後即可一鍵將內容發佈到 GitHub Pages
設定步驟
01 前往 GitHub → Settings → Developer settings → Personal access tokens → Tokens (classic)
02 建立新 Token，勾選 repo 權限（需要能寫入 repo）
03 複製 Token，貼到下方「Personal Access Token」欄位
04 填入你的 GitHub 帳號和 repo 名稱，儲存
05 之後每次編輯完，點上方「發佈到 GitHub」即可自動更新網站
Repository 資訊
驗證
Token 只存在你的瀏覽器 localStorage，不會上傳到任何地方。
發佈

點「發佈」會把目前後台的全部資料寫入 repo 裡的 data.json。
GitHub Pages 會在約 30 秒 ~ 2 分鐘內自動重新部署，網站訪客就能看到更新。
